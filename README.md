## 📂 File Structure
```
📦 project
├── android/            # Android 네이티브 프로젝트
|
├── assets/             # 이미지, 아이콘, 폰트 등 정적 리소스
├── components/         # 재사용 UI 컴포넌트
├── data/               # 목업 데이터 및 상수
├── hooks/              # 커스텀 훅
├── navigation/         # 화면 전환 및 네비게이터 설정
├── screens/            # 화면 단위 컴포넌트 (Login, SignUp, Main, Map 등)
├── services/           # API 통신 및 외부 서비스 연동
|
└── src/
    └── @types/
        └── svg/        # SVG 파일 import를 위한 타입 선언
```
